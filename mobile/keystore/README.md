# Ключ подписи Планера для Android

Этим ключом подписывается каждая версия `.apk`, поэтому новая версия ставится поверх старой и данные на телефоне сохраняются.

Ключ лежит здесь открыто, потому что секреты GitHub в этом репозитории не заданы. Сборка возьмёт ключ из секретов `ANDROID_KEYSTORE_BASE64` / `ANDROID_KEYSTORE_PASSWORD`, если они появятся, а иначе — отсюда.

Ставьте Планер только из раздела Releases этого репозитория.
