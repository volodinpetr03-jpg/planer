# Планер 3.16

Программа для Windows и Android: задачи, календарь, проекты и бюджет в одном окне.
Личные данные хранятся только на устройстве; общими бывают только проекты, отмеченные «Общий проект».

## Установка

1. Запустите `Planer-Setup-3.16.0.exe`. Права администратора не нужны.
2. Если Windows покажет «Система Windows защитила ваш компьютер» — нажмите **Подробнее → Выполнить в любом случае**.
3. Ярлык «Планер» появится на рабочем столе и в меню «Пуск».

Установка поверх прежних версий сохраняет все данные.

## Телефон Android

Файл `Planer-<версия>.apk` собирается автоматически на GitHub (раздел **Releases**). Перенесите его на телефон, откройте и разрешите установку. Новые версии ставятся поверх, данные сохраняются.

## Модули

- **Обзор** — план на сегодня, ближайшие дни, деньги, проекты, графики продуктивности и расходов.
- **Доска** — канбан-колонки, перетаскивание, чек-листы, повторы, напоминания, фильтры по проекту и тегам.
- **Календарь** — неделя по часам и месяц: задачи, регулярные платежи, сроки проектов, расходы по дням.
- **Проекты** — задачи, бюджет и срок проекта, график прогресса, расходы по категориям.
- **Бюджет** — счета, доходы и расходы, переводы, категории с месячными лимитами, регулярные платежи с напоминаниями, графики.
- **Инсайты** — статистика по продуктивности, срокам, загрузке и тратам.
- **Автоматизация** — правила, шаблоны, журнал.

Модули включаются и выключаются в «Настройки → Модули».

## Как всё связано

- Задача может принадлежать проекту и иметь теги. Расход можно привязать к задаче и проекту.
- Расходы проекта считаются в его бюджете, а выполненные задачи — в его прогрессе.
- Теги общие для задач и операций: нажмите на тег, чтобы увидеть всё, что с ним связано, и сумму расходов.
- Регулярные платежи и сроки проектов видны в календаре. Кнопка «Оплачено» сама записывает расход.
- На графиках можно нажимать: кусок диаграммы открывает операции категории, столбец — нужный месяц.

## Оформление

Настройки → Внешний вид: 5 тем (Графит, Светлая, Полночь, Тёплая, Контрастная) и «Как в Windows»,
10 акцентных цветов, 11 шрифтов, размер шрифта 11–22 px, масштаб интерфейса 70–160 % (Ctrl + / Ctrl − / Ctrl 0),
компактное меню.

## Данные

`%APPDATA%\Планер\planer-data.json`, рядом папка `backups` с ежедневными копиями (последние 14).
В настройках: резервная копия в файл, восстановление, выгрузка операций и задач в Excel (CSV).
